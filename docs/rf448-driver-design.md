# Client 448K 驱动设计

日期：2026-10-14。状态：用户已确认结构、固定频率和继电器关系；实现采用单一 Start(head, energy) 接口，并支持运行中同头调能量、停机复位头继电器。

## 范围与对象所有权

新增 `class/rf448_driver.h`、`class/rf448_driver.c`，以及 `class/mvc.h`、`class/mvc.c`。
`mvc_t` 按值拥有 `rf448_driver_t`，用 `MODUS_DECLARE_OBJECT` 实例化和注册；所有运行状态、请求、PT 游标及延时槽属于对应对象。
Driver 通过现有静态 MDI 资源控制硬件；板级 PWM 启停与安全输出能力在 `peripheral/at32f421/mdi/` 实现。
编译期已确定硬件，使用直接静态绑定，不引入运行时 ops 分派或通用命令驱动框架。

RF0I/RF0V 保留现有 ADC 通道，不实现反馈调节、物理量换算或闭环控制。
RL1/RL2/RL3 保留其现有默认值，头切换通过掩码只修改 RL4/RL5/RL6。
本驱动调节母线控制信号，不实现开关电源内部功能，也不承诺能量设定与实际母线电压之间的标定关系。

## 用户确认的头切换语义

外接接口为 RES 不锈钢电阻头、CAP 黑色电容头、COM 共用负极贴片、BIO+ 输出。
RL4/K2 切换 RF 通路；RL6/K1 切换 448K 电容或电阻头的负极回路。
用户确认：RL5/K3 吸合时，外部 COM 切到由 K1 选择的 448K 负极回路；未吸合时选择 BIO 回路。
软件以这项用户确认的控制语义为契约，不根据截图符号斜线另行定义应用行为。

| 头选择 | RL4/K2 | RL5/K3 | RL6/K1 |
|---|---:|---:|---:|
| 电容头 CAP | 0 | 1 | 0 |
| 电阻头 RES | 1 | 1 | 1 |

初始载波关闭、能量输出为零，RL4/RL5/RL6 均为 0。Start 在 IDLE 提交头和能量请求，Run 写入上述组合并以非阻塞 PT 等待稳定，等待期间新 Start 返回 BUSY。
稳定等待初值 30 ms，由配置字段 `wRelaySettleMs` 表达，允许根据真机动作及触点抖动调整。
控制信号稳定等待默认 1 ms，由 `wControlSettleMs` 表达。Stop 先关断 RF、输出零能量，再将 RL4/RL5/RL6 置 0；初始化和错误路径也执行这套安全输出。RL1/RL2/RL3 不被改写。

## 固定载波

PWM1N/PWM1P 由 TMR1 CH1/CH1C 输出互补波形。Driver 不提供频率和载波占空比调整 API。
板载 8 MHz HEXT 晶振经 `/2 × PLL 24` 产生 96 MHz HCLK；AHB 不分频，APB1/APB2 分频为 2，因此 PCLK 为 48 MHz、TMR1/TMR3 为 96 MHz。实际绝对频率精度由 8 MHz 晶振的容差和温漂决定。
TMR1 使用 ARR=213、周期 214 tick、比较值 107、deadtime=11 tick（约 114.6 ns，周期的 5.14%），两路有效高电平占空比均约为 44.86%。载波标称频率仍为 `96 MHz / 214 = 448598.13 Hz`，比 448 kHz 高约 0.134%。
这代表固定的标称 448K 频率，并非精确 448000 Hz。若用户要求精确 448000 Hz，需要另行确定可整除的时钟方案，再审计串口、ADC、时基等依赖。
停机时 SD 置 1、TMR1 主输出关闭，主通道与互补通道均保持低电平；启动前先准备计数器与互补输出，再解除 SD。

## 母线能量控制

DACPWM 使用 TMR3 CH1/PA6，定时器时钟 96 MHz、PSC=19、周期 1000 tick，输出 4.8 kHz。该值低于 GP8101 的 5 kHz 单周期识别分界，且在其 50 Hz～50 kHz 输入范围内。
API 的能量设定为无符号千分比 0～1000；它表示控制量，0 为最小、1000 为最大。
图一 Q8 反相，因此 MCU 端 PWM 比较值为 `1000 - energyPermille`；GP8101 输入占空比与请求值同向。
能量为 0 时 MCU 端必须持续高电平，使 Q8 导通、GP8101 输入为低。不能仅停止 TMR3 并让 PA6 留在低电平。
MDI 比较寄存器绑定须允许 compare=1000，以覆盖周期 1000 tick 的真正 100% 高电平。
PB1 经 S8050 反相驱动 IR2110 SD：MDI 逻辑 SD=1 时 PB1 输出低，Q5 截止，由上拉令芯片 SD 为高并关断；逻辑 SD=0 时 PB1 输出高，Q5 导通，将芯片 SD 拉低并放行。初始化期间先建立逻辑 SD=1 和 PA6 高电平，再交给 PWM 外设，避免输出意外开启。
Start 只提交目标；Run 内部依次完成关断、继电器切换、稳定等待、能量设置、控制信号等待和载波启动。
Run 使用 `BEGIN + while (1)` 持续 PT：启动后在运行循环内消费能量更新，STOP 完成清理后返回空闲请求等待。业务分支全部在 PT 内，外部仅保留参数与初始化/故障守卫。
两段启动等待均检查 STOP 或对象内 tick 截止时间到期，等待与运行中都能取消；STOP 与到期同时发生时优先停止。`lWaitDeadline` 由 `perfc_is_time_out_ms` 管理。
RUNNING 中再次 Start 且头类型相同，只提交能量更新；Run 应用后保持载波与继电器状态。换头、越界以及等待阶段的新请求均被拒绝，不改变当前目标。
DACPWM 运行中使用比较寄存器 preload，在下一个 PWM 周期更新，不重置计数器或触发软件更新事件。

## 公开 API

所有 Driver API 接收自身对象指针，返回明确结果码；查询通过只读状态快照。

- `rf448_driver_Init()`：校验依赖、继电器稳定时间并建立安全输出。
- `rf448_driver_Start(ptThis, head, energy)`：提交启动或 RUNNING 同头能量更新请求。
- `rf448_driver_Run()`：内部状态机推进启动时序并消费能量或停止请求。
- `rf448_driver_Stop()`：立即建立 SD 关断、关闭载波、输出零能量并复位三路头继电器。
- `rf448_driver_GetStatus()`：报告状态、最后错误、头选择及能量目标值。

`mvc` 按值拥有 Driver、基类和基类配置；由 `mvc_Run()` 调用 Driver Run 和状态快照，统一处理错误。恢复初始化时保留已注册基类，不重复插入注册表，也不改变对象 ID。
调试使用现有 MShell 命令注册及字符串解析 API：`rf448 start cap|res 0..1000`、`rf448 stop`、`rf448 status`。
不新增每周期日志或载波中断；硬件定时器自主产生 PWM。
