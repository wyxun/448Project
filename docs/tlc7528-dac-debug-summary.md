# TLC7528 双通道 DAC 调试与波形异常排查总结报告

## 一、 项目背景与硬件拓扑

本项目基于 **AT32F415RBT7** (144 MHz Cortex-M4) 主控芯片，通过双通道 8 位并口乘法型 DAC (**TLC7528CDWR**) 产生调幅波形，用于微电理疗输出。

### 1.1 硬件信号链路
1. **MCU 主控**：通过 GPIO 模拟并口数据线 (`PA0~PA7`) 与控制线 (`PB0: dac_oe`, `PB1: dac_wr`, `PB2: dac_ab`)；
2. **电平转换**：**TXB0108PWR** 将 MCU 侧的 3.3V 逻辑电平转换为 DAC 侧的 5.0V 逻辑电平；
3. **乘法型 DAC**：**TLC7528CDWR**（双通道 8 位电流输出型 DAC，5V 供电）：
   - **DACA（包络通道）**：参考电压 $V_{\text{REFA}}$ 接 2.5V 固定直流偏置，输出低频调制包络信号；
   - **DACB（载波通道）**：参考电压 $V_{\text{REFB}}$ 接入 DACA 产生的包络信号，输出高频载波（448kHz / 80kHz），实现两象限乘法硬件调幅；
4. **运放级 (LM324DR)**：
   - `OpAmp 2`（引脚 5, 6, 7）：DACA 反相跨阻放大，输出 `2OUT` (Pin 7)；
   - `C85 (100nF) + R66 (33kΩ)`：隔直高通滤波网络；
   - `OpAmp 1`（引脚 1, 2, 3）：电压跟随器缓冲，输出 `1OUT` (Pin 1) 送至 DACB 的 $V_{\text{REFB}}$；
   - `OpAmp 3`（引脚 8, 9, 10）：DACB 反相跨阻放大，输出 `3OUT` (Pin 8) 调幅信号；
   - `OpAmp 4`（引脚 12, 13, 14）：缓冲输出 `4OUT` (Pin 14)；
5. **后级功放**：**TDA2030A** 音频功率放大器 + **T2 升压变压器** 输出至电极。

## 二、 遇到的核心问题与根因排查

### 问题 1：正弦波严重破碎，呈多层阶梯状与梳状密集毛刺
- **现象描述**：
  在示波器上观察 DAC 输出，波形不是预期的连续正弦波，而是断裂成 4 层离散的台阶状点阵，且夹杂密集的毛刺（像梳子一样），无论调节频率还是幅度，台阶分布均未消失。
- **根因分析**：
  经逐层比对 MCU 管脚、TXB0108 电平转换芯片以及 TLC7528 原理图，理清了完整的数据总线链路：
  1. **MCU 端**：引脚 `PA0..PA7` 连到了原理图网络标号 `DA7..DA0`（**第 1 次交叉反序**）；
  2. **TXB0108**：`DA0..DA7` 直通 `D0..D7`；
  3. **TLC7528 端**：网络 `D0`（来自 PA7）连接到 TLC7528 的 **Pin 7 (DB7, MSB)**，网络 `D7`（来自 PA0）连接到 TLC7528 的 **Pin 14 (DB0, LSB)**（**第 2 次交叉反序**）；
  4. **硬件本质结论**：硬件走线在前后两端各反转了一次，**负负得正**！MCU `PA0` 最终物理连通至 TLC7528 的 `DB0 (LSB)`，`PA7` 连通至 `DB7 (MSB)`。
  5. **软件原错误**：原工程在 `peripheral/at32f415/mdi/instance.h` 中人为进行了反向引脚映射（误以为硬件只有一端反序），从而造成了**第 3 次反转**！
  - 最终导致向 DAC 写入的字节 **MSB 与 LSB 完全倒置**。最高有效位在低位跳变，正弦波被彻底切碎为 4 个离散大阶梯和锯齿毛刺。
- **解决方法**：
  修改 `peripheral/at32f415/mdi/instance.h`，将 `AT32_MASTER_DAC_PINS` 恢复为 1:1 直通映射：
  ```c
  #define AT32_MASTER_DAC_PINS(X, V, ...) \
      X(V, 0, 0, 0) X(V, 1, 1, 0) \
      X(V, 2, 2, 0) X(V, 3, 3, 0) \
      X(V, 4, 4, 0) X(V, 5, 5, 0) \
      X(V, 6, 6, 0) X(V, 7, 7, 0)
  ```
  修改后重新编译烧录，正弦波与调幅波彻底恢复平滑连续。

### 问题 2：320 kHz ISR 性能瓶颈与总线浮空时序隐患
- **现象与隐患**：
  1. 原驱动延时使用循环 `18 NOP`，在 144MHz 主频下单个延时超 125ns，在 320kHz 定时器中断中占用过多 CPU 周期；
  2. 初始化和停止阶段，在 `dac_oe=0`（总线处于高阻浮空态）时就发送写脉冲，可能触发 DAC 误写入不确定电平；
  3. 波形停止时未将 DAC 归中，导致关机后运放持续输出直流偏置。
- **解决方法**：
  1. 查阅 TLC7528 5V 手册规格（$t_{su}(DAC) \ge 50\text{ns}$, $t_{su}(D) \ge 25\text{ns}$, $t_w(WR) \ge 50\text{ns}$, $t_h \ge 10\text{ns}$），将延时精简优化为：
     - Setup 延时：`8 NOP` (~56 ns)
     - WR 脉宽：`9 NOP` (~63 ns)
     - Hold 保持：`4 NOP` (~28 ns)
  2. 修复 Init/Stop 流程：必须先将 `dac_oe` 置 1（开启总线驱动），再执行 WR 写脉冲；
  3. Stop 阶段原子写入 `128`（零点中值），保证静止状态下零偏置。

### 问题 3：示波器实测调幅波形 180° 倒相（波峰对应幅度最小）
- **现象描述**：
  示波器 CH2（蓝线）测包络波，CH1（黄线）测调幅载波。当蓝波处于正峰值（最高点）时，黄波的振幅收缩到最细；当蓝波处于谷值（最低点）时，黄波振幅展开到最大。
- **根因分析**：
  1. TLC7528 为电流输出型 DAC，运放配置为反相跨阻模式（$V_{\text{OUT}} \propto - V_{\text{REF}} \times \frac{D}{256}$）；
  2. DACA 数字码增大时，运放输出端模拟电压反而降低；
  3. 经过两级运放及参考极性传递，宏观上形成了标准的 **180° 反相调制**。
- **解决方法（已实现）**：
  在软件层 [`class/dac_driver.c`](file:///d:/1_project/13_448K/software/M448_master/class/dac_driver.c) 中将包络输出码取反：
  ```c
  chEnvelopeValue = (uint8_t)(255U - s_chSineTable[
      (uint8_t)(ptThis->tEnvelope.wPhase >> 24)]);
  ```
  软件负号与硬件反相运放抵消后，实现了波峰对应最大载波振幅（波峰对波峰）。

### 问题 4：示波器实测波形存在约 44° 相位错位与低频幅度衰减
- **现象描述**：
  在 `2OUT` (Pin 7) 观察蓝波包络与黄波载波时，极值点在时间轴上存在微小错位（约 2.4 ms，不是严格对齐）。将探头从 `2OUT` 移到 `1OUT` (Pin 1) 后，相移消失。
- **根因分析**：
  1. `2OUT` (Pin 7) 到 `1OUT` (Pin 1) 之间串联了隔直高通网络：**C85 (100nF)** 与 **R66 (33kΩ)**；
  2. 该高通滤波器的截止频率为：
     $$f_c = \frac{1}{2 \pi \cdot R_{66} \cdot C_{85}} = \frac{1}{2 \pi \times 33\,\text{k}\Omega \times 100\,\text{nF}} \approx 48.2\,\text{Hz}$$
  3. 实测包络频率正好在 **50 Hz** 附近，落在滤波器拐点上，导致产生显著的超前相移：
     $$\theta = \arctan\left(\frac{48.2}{50}\right) \approx 44^\circ \quad (\text{约 } 2.44\,\text{ms})$$
  4. 此外，50 Hz 信号在 C85 上被衰减了约 30% (-2.8 dB)；如果包络频率降到理疗常用的极低频（如 1Hz ~ 10Hz），信号将被电容几乎完全阻断（衰减达 -14dB ~ -34dB）并严重变形。

- **深度解析：为什么是“加大电容到 10μF”，这不是加大延迟吗？**
  很多工程师会根据 $\tau = RC$ 的直觉产生疑问：“加大电容充电变慢，延迟不是应该变大吗？”
  **答案是：这是因为混淆了“并联低通滤波”与“串联隔直高通”的物理机制：**
  
  1. **拓扑结构差异（并联 vs 串联）**：
     - **并联滤波（低通）**：电阻串在信号线上，电容并联到地。信号电压需对电容充放电才能建立，电容越大，充放电越慢，截止频率越低，信号**滞后延迟越大**（直觉适用的场景）；
     - **串联隔直（当前电路 C85）**：电容直接串联在信号主回路上，电阻 R66 对地。此时电容相当于信号通路上的一个**交流阻抗** $X_C = \frac{1}{2\pi f C}$。
  2. **交流容抗对比（以 50 Hz 为例）**：
     - 当 $C_{85} = 100\,\text{nF}$ 时：$X_C = \frac{1}{2\pi \times 50 \times 100\text{nF}} \approx \mathbf{31.8\,\text{k}\Omega}$！
       串联在通路上的电容阻抗居然高达 31.8 kΩ，几乎与后级电阻 R66 (33 kΩ) 相当，形成了巨大的阻碍，导致强烈的容性分压和 44° 超前相移；
     - 当 $C_{85} = 10\,\mu\text{F}$ 时：$X_C = \frac{1}{2\pi \times 50 \times 10\mu\text{F}} \approx \mathbf{318\,\Omega}$！
       串联阻抗骤降至 318 Ω，不足 R66 的 1%。**对 50 Hz 交流信号而言，10μF 电容几乎等效于一根直通导线（零阻抗通路）**，信号畅通无阻，相移自然逼近 0°。
  3. **数学公式证明（电容 C 在分母上）**：
     一阶串联高通滤波器的相移公式为：
     $$\theta = \arctan\left(\frac{1}{2\pi f \cdot R_{66} \cdot C_{85}}\right) = \arctan\left(\frac{X_C}{R_{66}}\right)$$
     可以看到，**$C_{85}$ 处于分母位置**：
     - $C_{85} = 100\,\text{nF} \implies \theta \approx \arctan(0.96) \approx 44.0^\circ$；
     - $C_{85} = 10\,\mu\text{F} \implies \theta \approx \arctan(0.0096) \approx \mathbf{0.55^\circ}$；
     - 当 $C \to \infty$（极限导线直通）时，$\theta \to \arctan(0) = \mathbf{0^\circ}$（完全零相移零延迟）。
  4. **加大电容唯一影响的“时间量”**：
     加大 C85 唯一增大的时间常数，是**刚上电/启动瞬间直流偏置电压的建立时间（瞬态稳定时间）**：
     $$\tau = R_{66} \times C_{85} = 33\,\text{k}\Omega \times 10\,\mu\text{F} = 0.33\,\text{s}$$
     即开机通电的一瞬间，电容两端需要约 $3\tau \approx 1$ 秒建立直流稳态；一旦建立完毕，在稳态运行期间，所有的交流包络正弦波都是 100% 实时、无延迟、无失真直通的。

- **解决方案**：
  - **硬件根治（强烈推荐）**：
    将 **C85** 从原有的 **100nF** 改换为 **10μF**（或 4.7μF ~ 22μF 贴片陶瓷电容）。
    - 截止频率推低至 $f_c \approx 0.48\,\text{Hz}$；
    - 50 Hz 时的稳态相移从 **44.0° 降至 0.55°**（在示波器上完全看不到相移）；
    - 50 Hz 幅度衰减从 -2.8 dB 恢复为 0 dB（完全无损）；低至 2Hz~5Hz 的超低频理疗信号也能完整通过。
  - **测量准则**：
    调试与验证调幅信号时，探头应测量 **`1OUT` (Pin 1)**，因为 `1OUT` 才是 DACB 真正的调制基准。
